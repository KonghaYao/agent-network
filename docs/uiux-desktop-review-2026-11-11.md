# 桌面端 UI/UX 审查（2026-11-11）

在独立 worktree 使用真实服务、合成账号和 Chromium 验证 1024×600、1200×600、1280×400、1440×768、1920×1080 的会话列表、建群、好友、配对、聊天、群设置、文件和网页监控面板；检查视口内操作、可用内容高度、横向溢出及分栏后的标题宽度，并模拟弹窗打开时缩短窗口。1024px 属于平板式抽屉布局，1200px 起为桌面分栏。

## 修复

- **短窗口配对操作不可达：** 1280×400 下二维码加载完成后，“关闭”曾落在视口外（底部约 501px）。桌面配对弹窗改为固定可见页头与底部操作，中间内容独立滚动；窗口缩高或滚动内容时仍能关闭。
- **分栏标题宽度不足：** 1280px 默认双栏时群名仅获得约 165px，较长名称易裁切。将标题区的最小宽度略增，使窄聊天栏的操作行换行；同一视口标题获得约 405px，宽屏布局不变。

验证：`bun scripts/ux-luna/desktop-layout.ts`，并纳入 `bun run test:ux`。浏览器模拟不替代实体设备及各操作系统窗口管理器的人工检查。
