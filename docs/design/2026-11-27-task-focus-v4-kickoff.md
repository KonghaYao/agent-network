# WeBots v4.0 Task Focus 开工包

交给 ultracode 协调与实施团队。唯一发布里程碑为「个人 KanBan 切换完成」。

用户从聊天左下角开启自己的全局秘书。每人一名秘书、一个固定会话、一张跨群和私聊的私人看板。秘书建卡和更新，卡主决定归档。WeBots 管身份、授权、Watch、日志和卡片，独立部署的 Peri-Swarm 经官方 SDK 执行 Agent。

1. 先读设计第 1、2 节了解双人灰度发布场景，打开离线 HTML 走一遍浮窗、快速跳转与返回。[主设计](./webots-task-focus-design.md) · [交互模拟](./webots-task-focus-demo.html)
2. 按第 6、6.1 节分派八个工作包。TF-01 先交每个事件对两位用户的期望结果和接口样例。同步让运行时组验证同根撤权，让迁移组盘点两代旧 Task。开工基线为 WeBots `1b8ccc65`、Peri `b2dcabfa`、`openai@7.60.0`。
3. 首次联调交一张真实个人卡。记录原消息、静默领取、无 @ 改期、私聊交付、MCP 写卡及点击回原文的关联 ID。对另一位用户、另一位工作 Agent 和重复事件分别核对结果。
4. 每组回传对应工作包、代码版本、使用的输入、观察到的结果和未通过项。发布负责人按第 7 节汇总 P0、P1，核对同根撤权、旧 Task 零残留、原生 IM 保全和 10 万事件结果。

HTML 中的消息和卡片变化由演示数据驱动。真实模型、跨服务执行和正式 IM 的验收在实施期间完成。
