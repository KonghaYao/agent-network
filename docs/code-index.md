## 边界与数据流

客户端 → `POST /mcp` → `src/app.ts` → 官方 MCP TS SDK（仅 `2026-07-28`）→ `src/mcp/tools.ts` / `resources.ts` / `room-files.ts` → `src/domain/` → SQLite。文件上传 → `POST /mcp-upload` → MCPP Files v1 → FlyDrive；房间文件元数据写入 SQLite `room_files`，文件所有权、可见性（默认公开）、保留状态与引用写入 `drive_files` / `artifacts` / `file_references`，下载统一走 `GET /f/:fileId`（默认公开可读；显式撤销后要求短时票据；HEAD/Range/304/`?download=1` 同一授权）。浏览器 → `GET /a/:sessionId` → `src/storage/queries.ts` 按 session 查 actor → `src/web/share.ts` 渲染分享页；建联后跳转 `GET /c/:roomId`。`GET /` 与 `GET /c/:roomId` 都由 `src/web/chat.ts` 的 `renderAppPage` 渲染同一套微信风双栏外壳：左侧 280–320px 会话栏（搜索、64px 会话项、群聊 2×2 头像、未读红点、底部用户/扫码），右侧空状态或聊天区（时间胶囊、左右气泡、36px 头像、群聊发送者、@ 高亮、回执）；桌面打开文件或监控面板时，聊天区与右栏默认 50/50，可拖动分隔条调整并记住比例，关闭面板后聊天占满；移动端按 `<body>` 的 `page-home` / `page-room` 切为单栏。首页由 `share.ts` 的 `renderHomePage` 委托。页面内联脚本用浏览器 token 调用同一 `/mcp`；`GET /` 无 token 时列表区只显示引导，页面不再提供“服务信息”折叠区。
