## 最终行为与变更

### 1. 新增 Q04 验收脚本

- `scripts/verify-q04.ts`：自托管临时 Bun 实例（随机端口、独立 `DATA_DIR`/数据库、`PUBLIC_ORIGIN` 与 `AGENTNET_URL` 一致、短 presence 窗口），Playwright Chromium 在 1280×900、768×1024、390×844 三档及浅色/暗色下执行。
- `scripts/lib/q04-harness.ts`：临时服务、真实 MCP `rawRpc` 对账、浏览器上下文、MCP 调用/流信号跟踪、上传与截图。
- `scripts/lib/q04-fixture.ts`：合成 U1–U5、B1–B4；B1 通过真实“新建 Agent”弹窗创建，B2/B3 同管理者创建，B4 走 Agent 发起 + human 确认的认领入口。
- `scripts/lib/q04-groups.ts`：好友申请/拒绝/接受、拉黑/解除、UI 建群多选、角色任免、owner 退群拒绝、在途任务退群预览、定向邀请、邀请链接审批、重复扫码、移除成员、无主群拒绝加入、owner 转让、解散归档。
- `scripts/lib/q04-chat.ts`：文本发送、同名 Agent @ 选择器与显式 invoke、人类 mention、文件上传/绑定/预览/下载、失败重试、未读、断线补读、投递回执。
- `scripts/lib/q04-tasks.ts`：从消息建任务、接受、进度/阻塞/恢复、交接、交接包授权、提交 v1、退回、重新提交 v2、逐项验收、取消、领取冲突、执行未知/对账、failed 重试。
- `scripts/lib/q04-agents.ts`：停用/启用/归档、已归档浮层、管理权交接、旧管理者失权、旧运行 token 失效、在途任务 blocked。
- `scripts/lib/q04-responsive.ts`：三档视口 × 明暗主题、Tab/Esc、Shift+Enter/Enter、组合输入（compositionstart/compositionend、isComposing、keyCode 229、80ms 守卫）、tap、空态、列表失败重试、P1 缺口不伪造判断。
- `scripts/lib/q04-identity.ts`：真实配对弹窗 → `/pair` → 确认 → 新设备独立 token、挑战重放拒绝、单设备撤销、失效设备重新配对待办、身份切换/退出/切回。

### 2. 最小 UI 修复（未改后端语义）

1. `src/web/join.ts`：`next_step=member` 时 `can_respond=false`，原逻辑把“进入群聊”按钮设为禁用，用户已加入后没有下一步。改为成员入口保持可用，点击直接进入群聊。
2. `src/web/chat-script.ts`：建群弹窗支持 Esc 关闭；此前只有取消按钮与点击遮罩，键盘用户无法关闭。

## 问题与限制

1. 网页没有独立“设备列表/撤销”管理页，单设备撤销走 MCP 明确入口；失效设备页面会显示重新配对入口。该缺口与 `docs/feature-matrix.md` 已记录一致。
2. Agent 认领没有独立 Web 入口，走 Agent 发起 + human 确认的 MCP 入口；本轮验证了绑定结果，未伪造 UI。
3. A04 备注、G04 群昵称/公告版本冲突、M01 草稿/置顶/静音、M04 引用、M05/M06 媒体/转发/撤回、M08 搜索/收藏/置顶、M09 通话、Q03 外部回写、Q06 容量均为 P1，未在本轮签收。
4. Q04 的任务 failed 分支用 SQLite 夹具注入终态，随后重试仍走真实 UI 与 `network_task_retry`；不声称自然业务路径可产生 failed。
5. 本轮未部署、未访问生产、未创建 PR；最终集成 SHA 由集成人确认后，独立验证者需在集成版本重跑受影响路径。
