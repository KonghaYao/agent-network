## 长路径与一致性

- 消息操作只渲染一个入口，菜单按需创建并委托事件，避免每条消息常驻多个操作按钮。
- 返回历史阅读位置使用稳定消息锚点；初次 Markdown 重建完成前继续补偿高度变化。用户滚轮、触摸、键盘或拖动滚动条立即结束该恢复状态。
- 连续上翻时，分页完成后复查顶部位置，避免加载中的滚动事件被单飞锁挡住后永久停住。
- 在线撤回更新当前/非当前缓存，清理展开正文和引用草稿。重连补读所有已缓存房间，逐批最多 5 页并续接，避免后续房间饥饿。
- 游标失效直接丢弃目标房间缓存；失去成员资格立即隐藏正文、清理展开缓存并禁用发送。不同房间错误互不阻断。
- 撤回保留消息定位，发送重试仍幂等；审计仅保存原文哈希。禁止撤回已产生 Agent 投递或被任务引用的消息，不把撤回伪装成取消工作。
- 新增 `network_message_search`、`network_message_context`、`network_message_recall`，权限复用现有房间历史边界。没有新增表、列或迁移，也没有新增依赖。

## 复跑与应用

依赖沿用现有锁文件。安装 Playwright Chromium，或设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指向本机可执行文件。

```sh
bun run typecheck
bun run test:ux
bun run test:hotpaths
bun run test:web
PERF_WEB_MESSAGES=2000 bun run test:web:perf --out /tmp/webots-long-history.json
```

`test:ux` 每组创建独立临时服务、SQLite 和合成账号，结束后清理。报告位置可用 `UX_OUTPUT` 指定；失败以非零状态退出。原有 `test:protocol` 和 `test:acceptance` 需要用 `AGENTNET_URL` 指向隔离测试服务，相关存在性/文件测试同时设置其 `DATA_DIR` 和 `PUBLIC_ORIGIN`，不要对生产实例运行测试夹具。

交付补丁为单提交邮件格式。在相同基线检查后可用：

```sh
git apply --check webots-ux-fixes-e7a9af5.patch
git am webots-ux-fixes-e7a9af5.patch
```

如果主线已前进，维护员应先检查冲突并复跑，不能据此报告认定新主线已经通过。此交付没有直接推送、合并或部署。

## 明确边界

- 置顶和免打扰仅当前浏览器生效；不是跨设备设置同步。分类徽标统计当前已加载会话。
- 转发支持文字，不自动唤醒 Agent；附件跨房间权限转交没有实现，界面会明确阻止附件转发。
- 撤回仅限本人、人类身份、两分钟内的普通消息；不撤销任务、Agent 投递、已下载文件或已复制内容。
- 搜索为有界输出的 SQLite 子串查询，没有引入 FTS；十万级历史检索尚未压测。
- 未覆盖真实系统输入法、真实 iOS/Android、生产网络及多实例部署。
